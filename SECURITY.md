# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's private vulnerability reporting: **Security → Report a vulnerability** on this repository. Include a description, the affected screen or module, and steps to reproduce.

You can expect an acknowledgement within 7 days. Fixes are released as a new version, and the advisory is published after the fix ships.

## Scope

In scope: authentication, data exposure, insecure storage on the device, and issues in how the app calls the backend.

Out of scope: issues in third-party services, rooted or modified devices, and findings that require physical access to an unlocked device.
